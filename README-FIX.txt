📖 এই প্যাকেজে কী আছে?
তোমার GitHub রিপোর সম্পূর্ণ কপি, যার ভেতরে নিচের ৬টা ফাইল ঠিক করা:

  ১) web/template/webav.html        ← ওয়াচ পেজ (প্লেয়ার)
  ২) web/utils/render_template.py   ← পেজ রেন্ডার (নাম + মুভির ছবি)
  ৩) web/utils/file_properties.py   ← নাম হেল্পার (নতুন)
  ৪) web/stream_routes.py           ← স্ট্রিম সার্ভার + 🖼️ নতুন /thumb রাউট
  ৫) plugins/private_stream.py      ← ফাইল স্ক্যান হ্যান্ডলার (তোমার নাম)
  ৬) plugins/channel_stream.py      ← চ্যানেল পোস্ট হ্যান্ডলার (তোমার নাম)

────────────────────────────────────────────────────────────────
🔧 যা যা ঠিক করা হয়েছে
────────────────────────────────────────────────────────────────

১) অটো-প্লে সম্পূর্ণ বন্ধ ✅
   • এখন পেজ খুললেই: মুভির ছবি + ডিউরেশন (০০:০০ / ২:০৯:৪১) দেখাবে,
     ভিডিও থামা থাকবে, কোনো আওয়াজ হবে না।
   • ইউজার প্লে চাপলে তবেই সাউন্ডসহ প্লে হবে।

২) মুভির ছবি (পোস্টার) এখন ১০০% আসবে ✅
   • আগে: ছবি ভিডিও থেকে আঁকা হতো — HEVC 10-bit ফাইলে ব্রাউজার
     ফ্রেম ডিকোড করতে না পারায় কালো থাকত।
   • এখন: টেলিগ্রাম প্রতিটি ভিডিওর জন্য যে স্ক্রিনশট বানায়, সেটাই
     নতুন /thumb রাউট দিয়ে সাথে সাথে দেখানো হয় — কোডেক যা-ই হোক,
     ছবি তৎক্ষণাৎ আসবে। (ভিডিওতে ছবি না থাকলে পুরনো ক্যানভাস পদ্ধতি
     ফলব্যাক হিসেবে আছে।)

৩) সাপ-লোডিং গেম ফেরত ✅ (আরও ভালোভাবে)
   • প্লে চাপলে সাপ-গেম দেখাবে — আসল বাফার প্রগ্রেস (৫ সেকেন্ড = ১০০%)।
   • ১০০% হলেই সাথে সাথে সাউন্ডসহ প্লে — কোনো অপেক্ষা নেই।
   • ৯৫%+ এ ৭ সেকেন্ডের বেশি আটকে থাকলে নিজে থেকেই ১০০% হয়ে প্লে হবে
     — ৯৯%-এ ঘুরে ঘুরে আটকে থাকার ফাঁদ আর নেই।
   • দূরে সিক দিলেও একই গেম দেখাবে, রেডি হলেই ওখান থেকে প্লে।
   • গেমের সময় ইউজার ট্যাপ করলে বন্ধ হয়ে থামবে (আগের মতোই)।

৪) কালো স্ক্রিন ফিক্স (ছবি নেই, আওয়াজ আছে) ✅
   • নতুন BLACK-SCREEN RECOVERY: প্লে চলছে কিন্তু ছবি আসছে না ধরতে
     পারে (requestVideoFrameCallback দিয়ে), তাহলে নিজে থেকেই:
     মাইক্রো-নাজ → ছোট রি-সিক → আরও হলে ইউজারকে হিন্ট দেখায়।
   • তোমার "+১০ সেকেন্ড স্কিপে ছবি আসে" সমস্যাটা এটা দিয়ে অটো-ঠিক হবে।
   • ⚠️ গুরুত্বপূর্ণ: "Immortal 2026 720p 10bit DS4K" — এই ফাইলটা HEVC
     10-bit কোডেকের। অনেক ব্রাউজার/ফোনের হার্ডওয়্যার এটা ডিকোডই করতে
     পারে না। সার্ভার যত ফাস্টই হোক, এমন ফাইল সব ডিভাইসে ব্রাউজারে
     চলবে না। ফিউচারের আপলোডে **H.264 / x264 / AV** লেখা রিপ দিলে
     ১০০% ডিভাইসে ব্রাউজারে চলবে। (আওয়াজ/ডাউনলোড/MX-VLC সবসময় চলবে।)

৫) ফাইলের নাম = তোমার দেওয়া নাম ✅
   • মুভি স্ক্যান করার সময় তুমি যে নাম লিখো (ক্যাপশনের প্রথম লাইন),
     সেটাই এখন:
       - ওয়াচ পেজের টাইটেল ও হেডারে দেখাবে
       - "YOUR LINK GENERATED!" মেসেজে দেখাবে
       - লিংকের ভেতরেও থাকবে (যেমন: .../watch/1601/Immortal (2026)
         Hindi Dubbed Full Movie HD.mkv?hash=...)
   • ক্যাপশন না দিলে আগের মতো আসল ফাইলের টেকনিক্যাল নাম দেখাবে।
   • চ্যানেল পোস্ট আর গ্রুপ /link কমান্ডেও একই নিয়ম।
   • পুরনো সব লিংক এখনও কাজ করবে (লিংক id+hash দিয়ে চেনা হয়,
     নাম শুধু দেখার জন্য)।

৬) আগের সব ফিক্স অক্ষত আছে ✅
   • স্ট্রিম ওয়াচডগ (idle ২৫s → ছেড়ে দিয়ে রিট্রাই), প্রথম-চাংক
     টাইমআউট, 504 অটো-রিট্রাই, ক্লায়েন্ট হেলথ/কুলডাউন, প্রিওয়ার্ম,
     FloodWait রিট্রাই, mime ফিক্স — সব আগের মতোই চলছে।
   • তোমার প্রিমিয়াম ক্লায়েন্ট রাউটিং (2GB-র বড় ফাইল প্রিমিয়াম
     সেশনে) অক্ষত — ৪টা ক্লায়েন্ট (MULTI_TOKEN + MULTI_SESSION) আগের
     মতোই কাজ করবে।
   • 💰 অ্যাড: Adsterra ২টা ব্যানার + popunder + direct link + স্ট্রিম
     অ্যাড ইঞ্জিন + interstitial — একটাও ছোঁয়া হয়নি।

🧪 টেস্ট রিপোর্ট (আমি নিজে ব্রাউজারে প্লে করে দেখেছি)
────────────────────────────────────────────────────────────────
   ✔ পেজ খুলেই: থামা + ছবি + ডিউরেশন + "Ready" — কোনো অটো-প্লে নেই
   ✔ প্লে চাপতেই: সাপ-গেম শুরু (৬৫% → বাড়ছে)
   ✔ ১০০% হলেই: সাউন্ডসহ প্লে (muted=false যাচাই করা)
   ✔ ৮০% দূরে সিক: গেম দেখাল → ওখান থেকে প্লে ফিরল
   ✔ JS সিনট্যাক্স + পুরো রিপো Python কম্পাইল পাস

🚀 কীভাবে ডিপ্লয় করবে (২ মিনিট)
────────────────────────────────────────────────────────────────
পদ্ধতি ১ — GitHub-এ (সবচেয়ে সহজ):
   ১. ZIP খুলো → ফাইলগুলো দেখো (রিপোর স্ট্রাকচার হুবহু আছে)।
   ২. তোমার GitHub রিপো (Sakib122/MovieBoxBDStreamBot) খুলো।
   ৩. এই ৬টা ফাইল এক এক করে ওপেন করে ✏️ Edit → নতুন কনটেন্ট পেস্ট
      → "Commit changes":
        - web/template/webav.html
        - web/utils/render_template.py
        - web/utils/file_properties.py
        - web/stream_routes.py
        - plugins/private_stream.py
        - plugins/channel_stream.py
      (অথবা পুরো ফোল্ডারের ফাইলগুলো আপলোড করে রিপ্লেস করো)
   ৪. Koyeb অটোমেটিক নতুন করে ডিপ্লয় করবে (~২-৩ মিনিট)।
   ৫. একবার বটকে /start দিয়ে চেক করো।

পদ্ধতি ২ — পুরো ফোল্ডার আপলোড:
   GitHub রিপোর "Add file → Upload files" দিয়ে ZIP-এর ভেতরের সব
   ফাইল ড্র্যাগ করে দাও → Commit।

⚠️ গুরুত্বপূর্ণ: এই প্যাকেজে .env ফাইল ইচ্ছা করে রাখা হয়নি —
   তোমার API_ID / BOT_TOKEN / DATABASE_URI এগুলো Koyeb-এর
   Environment Variables-এ আগেই সেট করা আছে, কিছু বদলাতে হবে না।
   এই ফাইলগুলো কখনো GitHub-এ পাবলিক করে আপলোড করো না!
